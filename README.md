RailBlock AI is an autonomous, AI-driven maintenance block planning optimizer for Indian Railways.

## Quick Start

```bash
docker-compose up
```

Access the UI at http://localhost:3000 or API docs at http://localhost:8000/docs

## Tech Stack

- **Backend**: FastAPI + Python 3.11
- **Solver**: Google OR-Tools CP-SAT
- **Database**: PostgreSQL 15
- **Frontend**: React 19 + TypeScript + Tailwind CSS + Vite
- **Deployment**: Docker Compose
